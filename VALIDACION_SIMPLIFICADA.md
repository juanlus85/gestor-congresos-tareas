# Validación de la interfaz simplificada

La vista previa autenticada se comprobó el 8 de septiembre de 2026 tras simplificar el producto. El menú presenta seis áreas exclusivas para organizadores: Mis tareas, Todas las tareas, Personas, Grupos, Categorías y Congresos. La vista de organizador muestra correctamente las 152 tareas del congreso activo, los recuentos por estado y el acceso de administración.

La aplicación se ha rediseñado para separar congresos, categorías, grupos y asignaciones múltiples. La API restringe las vistas de colaboradores a las tareas asignadas directamente o a través de un grupo. La comprobación de estado no muestra errores de TypeScript ni del servidor.
